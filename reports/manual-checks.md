# Визуальная проверка

Дата: 09.11.2026. Среда: Windows, Python 3.12, Tkinter 8.6.

- Приложение запущено командой `python main.py`.
- Просмотрены все три вкладки: подписи и элементы помещаются в окне,
  кнопки и поля доступны, основные элементы не перекрываются.
- На вкладке рисования перетаскиванием мыши нарисован синий прямоугольник.
  После отпускания он остался на холсте, счётчик показал «Фигур: 1».
- На вкладке конвертера нажата кнопка «Конвертировать»:
  отображено `100 USD = 9000.00 RUB` при учебном курсе USD=90.
- Ввод текста, выбор списка, другие фигуры, ошибки и меню выхода дополнительно
  проверены интеграционными тестами в `tests/test_gui.py`.

Этот отчёт описывает локальную проверку, а не результат бота или GitHub Actions.
