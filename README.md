## Цель

Освоить создание графических интерфейсов, компоновку виджетов и обработку
событий. Работа выполнена на Python и Tkinter из стандартной библиотеки.
Источник задания: методичка «Методы и технологии программирования», часть 1,
лабораторная №5, страницы 9–10. По строке варианта 2 требуются средние задания
2, 4, 7 и повышенные 2, 6.

## Соответствие варианту

| Уровень | Задание | Реализация |

| Среднее №2 | Окно с текстовым полем и кнопкой, выводящей текст | Entry, Button, Label; `show_text()` |

PyQt не нужен: задание с обязательным PyQt5 имеет номер 10 и не входит в вариант 2.

## Запуск

Требуется Python 3.10 или новее с Tkinter и графический рабочий стол.
В стандартном установщике Python для Windows должен быть включён компонент
Tcl/Tk. Сторонних Python-зависимостей нет.

Из папки проекта:

```bash
python main.py
```

При наличии Windows Python Launcher также можно использовать `py main.py`.
Открывается окно с тремя вкладками. Программа работает до закрытия окна
или выбора «Файл → Выход». Импорт модулей сам по себе окно не создаёт.

## Как проверить задания

1. **Текст и список.** Ввести «Привет, Tkinter!» и нажать «Показать» либо Enter.
   Текст появится под полем. Пустой ввод выдаст понятное сообщение.
   Выбрать строку списка — под ним отобразится выбранная тема.
2. **Рисование.** Выбрать прямоугольник, эллипс или линию и цвет.
   Зажать левую кнопку на белом холсте, переместить мышь и отпустить.
   Фигура отображается уже во время движения. Можно рисовать в любом
   направлении. «Отменить фигуру» удаляет только последнюю фигуру.
   Щелчок без движения не создаёт вырожденную фигуру.
3. **Конвертер валют.** Ввести сумму, выбрать исходную и целевую валюту,
   нажать «Конвертировать». При учебном курсе 90 RUB за USD:
   100 USD = 9000.00 RUB. Изменить курс USD на 80 и повторить:
   результат 8000.00 RUB. Некорректный ввод выводится в области результата.
4. **Меню.** Выбрать «Файл → Выход»: окно и цикл событий завершаются.
   Также работают Ctrl+Q и системная кнопка закрытия.

## Устройство программы

```text
main.py                       # Точка входа и mainloop
lab5/app.py                   # Окно, виджеты, обработчики событий
lab5/logic.py                 # Валидация, расчёт валют, границы фигур
tests/test_logic.py           # Независимые проверки вычислений
tests/test_gui.py             # Тесты настоящих Tk-виджетов и событий
reports/local-checks.txt      # Фактический вывод локального запуска тестов
reports/manual-checks.md      # Результат визуальной проверки
.github/workflows/python-check.yml
```

`LabApp` наследуется от `tk.Tk`. `Frame` и `Notebook` группируют виджеты;
`pack` размещает основные блоки, `grid` — поля внутри формы.
В одном и том же контейнере эти менеджеры компоновки не смешиваются.
`StringVar` связывает значения с надписями и полями, `command` связывает
кнопки с обработчиками. `mainloop()` принимает события и обновляет окно.

Для рисования используются `<ButtonPress-1>`, `<B1-Motion>` и
`<ButtonRelease-1>`. При нажатии создаётся элемент Canvas, при движении
обновляются его координаты, при отпускании элемент сохраняется в списке.
Границы прямоугольника и эллипса нормализуются через min/max, направление
линии сохраняется. Координаты ограничены размерами холста.

## Правила конвертации

Курсы учебные, не являются текущими банковскими курсами. В интерфейсе это
явно указано. Начальные значения: RUB=1, USD=90, EUR=100, CNY=12.5 рублей
за единицу валюты. Любой курс кроме базового RUB можно изменить вручную.
Сеть и API не используются, поэтому демонстрация воспроизводима офлайн.

Формула: **результат = сумма × курс исходной валюты / курс целевой валюты**.
Используется `Decimal` с округлением `ROUND_HALF_UP` до двух знаков,
а не двоичная арифметика float. Сумма допускается от нуля до миллиарда,
курс — строго больше нуля и не больше миллиарда; до шести дробных знаков.
Точка и запятая поддерживаются. NaN, бесконечности, экспоненциальная запись,
отрицательные значения и посторонние символы отклоняются.
При изменении входных данных старый результат заменяется приглашением
повторить расчёт, чтобы не показывать устаревшее значение.

Ограничения: введённые курсы и рисунок хранятся только в памяти до закрытия.
Сохранение рисунков и получение курсов из сети не входят в задания варианта.

## Проверка

```bash
python -m unittest discover -s tests -t . -v
```

Локально на Windows, Python 3.12.14, Tk 8.6.12 выполнено **20 тестов,
все прошли**: 10 тестов логики и 10 интеграционных тестов интерфейса.
Проверены известные суммы, округление, ноль, некорректные курсы,
крупные значения, ввод текста, выбор списка, направления рисования,
отмена фигуры, обновление результата и закрытие через меню.
Тесты GUI требуют доступного дисплея и не пропускаются молча.
Для запуска только вычислительных тестов без дисплея:

```bash
python -m unittest tests.test_logic -v
```

[Фактический журнал](reports/local-checks.txt) содержит проверенный коммит кода.
Последующие изменения документации не меняют проверенные исходники.

Workflow GitHub Actions настроен на Windows и Python 3.10, 3.12, 3.14.
